# Agent-run businesses · mesh · scarce drops

Demos where agents *operate* a business — running a shop, managing a neighborhood mesh, gating a scarce drop — not just transacting on a user's behalf.

| Demo | Port | What it shows |
|---|---|---|
| [`mint-business/`](./mint-business) | 3265 | Agent-run micro-business — autonomous shop with P&L, dividends, all governed by Sly. |
| [`nest-block/`](./nest-block) | 3264 | Neighborhood agent mesh — borrow a drill, hire a dog-walker, lend a spare key. Peer-to-peer with spending policy + KYA tier. |
| [`velvet-tickets/`](./velvet-tickets) | 3262 | KYA-gated scarce drops. No scalper bots, no fake queues — tier requirement enforced by Sly before the ACP checkout. |
